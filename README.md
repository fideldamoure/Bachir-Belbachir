# تطبيق الرقابة والتدقيق لمسابقات التوظيف – ولاية تلمسان (Android / Capacitor)

مشروع Capacitor يغلّف الصفحة `src/index.html` داخل تطبيق أندرويد. كل المكتبات (Tailwind وFontAwesome وخط Cairo وjsPDF وhtml2canvas) تُنسخ محلياً، فيعمل التطبيق **بدون إنترنت**.

## المتطلبات على جهازك
- Node.js 20 أو أحدث
- Android Studio (يتضمن Android SDK) وJDK 21

## الخطوات

```bash
cd tlemcen-audit-app
npm install                 # تثبيت المكتبات
npm run build               # نسخ المكتبات محلياً وبناء Tailwind في مجلد www/
npx cap add android         # مرة واحدة فقط: إنشاء مشروع أندرويد
npx cap sync android        # مزامنة www والإضافات مع مشروع أندرويد
```

### بناء ملف APK للتجربة
```bash
cd android
./gradlew assembleDebug     # على ويندوز: gradlew.bat assembleDebug
```
الملف الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`

أو افتح المشروع في Android Studio: `npm run open` ثم Run ▶.

### بناء نسخة للنشر (AAB / APK موقّع)
من Android Studio: Build ▸ Generate Signed Bundle / APK. احتفظ بملف المفتاح (keystore) وكلمة مروره في مكان آمن.

## بعد أي تعديل على الصفحة
عدّل الملف `src/index.html` ثم نفّذ: `npm run sync` وأعد البناء.

## ما الذي تغيّر عن الملف الأصلي
- استبدال روابط CDN بملفات محلية.
- زر «تصدير البيانات» يحفظ نسخة JSON ويفتح نافذة المشاركة في أندرويد (الطريقة القديمة لا تعمل داخل WebView).
- زر الطباعة صار «حفظ / مشاركة المحضر (PDF)» لأن `window.print()` لا يعمل في تطبيقات أندرويد؛ يُنشأ PDF من المحضر ويُشارك.
- منطق التنقيط والتدقيق والحفظ في `localStorage` دون تغيير.

## تنبيهات
- البيانات تُحفظ داخل التطبيق فقط وتُمسح عند «مسح بيانات التطبيق» أو إلغاء تثبيته، فاستخدم «تصدير البيانات» لأخذ نسخ احتياطية دورية.
- الملف يحتوي بيانات شخصية (أرقام بطاقات التعريف)، فتعامل مع النسخ المُصدَّرة وفق قواعد حماية المعطيات الشخصية.
- لم يُجرَّب البناء على جهاز أندرويد حقيقي قبل التسليم، فجرّب التصدير والـPDF على هاتفك أولاً.
